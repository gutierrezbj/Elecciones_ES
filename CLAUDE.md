# Guía para Claude Code

Seguir **AGENTS.md** como contrato técnico y **docs/PLAN.md** como plan.

Rol propuesto: auditor independiente de metodología, calidad de datos y código. Antes de implementar, revisar definición de campos, trazabilidad, controles de calidad, cobertura y posibles falsos positivos. Proponer cambios mediante pull requests separados y nunca afirmar irregularidades sin acta o documento comprobable.

Primer encargo recomendado: revisar el catálogo de fuentes, diseñar esquema canónico para Congreso y Senado separado, y una matriz de verificabilidad del voto por correo (disponible / agregado / restringido / inaccesible). Documentar riesgos estadísticos y legales.

La autorización de acceso al repositorio se configura fuera de estos archivos en las integraciones de GitHub de Claude.
